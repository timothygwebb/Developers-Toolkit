# 30-Day Series: Topic Calendar (template)

Use this file as a template for a daily series. Replace the example topics
below with your own. Keep the queue format: one article per day, in order,
check off as posted (move file from `queue/` to `posted/`).

## How to use this template
- Pick a series theme, then write 30 topics that build on each other.
- Each topic: a slug (`NN-topic-slug`), a title, and a one-line description
  of what the article will prove or teach. No topic should depend on a
  personal story, client, or project the reader cannot verify.
- Example site: your-site.wordpress.com. Example topics below are
  generic developer / independent-builder topics, not a personal series.
